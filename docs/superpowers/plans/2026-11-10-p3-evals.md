# P3: suíte de evals do MCP server de legislação, plano de implementação

> **Para quem executa:** a forma de execução já está decidida na spec (D11): **sem Meister**, na conversa, **um passo por vez** (`step-NN`), com **TDD**. As tarefas marcadas **[ENTORNO]** são feitas por um subagente **Haiku 5.5** com o texto da tarefa como único contexto, e a sessão principal confere (testes rodando, diff lido) antes de commitar. As tarefas marcadas **[NÚCLEO]** são **escritas pelo usuário**; o Claude só revisa, explica e pergunta, e **nada** delas é delegado. Os passos usam `- [ ]`.

**Objetivo:** uma suíte offline-testável que mede a qualidade do MCP server do P2, com 100 casos anotados, juiz LLM calibrado por TPR/TNR e relatório antes/depois que o CI confere.

**Arquitetura:** pacote Python `evals/` com módulos pequenos e de uma só responsabilidade. Os dados (casos, anotações, vereditos do juiz, relatórios) são JSON versionado; os traces reais ficam fora do git. As rodadas pagas (Claude Code e juiz) são comandos separados, com teto de custo; o CI só roda o que é offline.

**Stack:** Python 3.13, `uv`, `httpx` (cliente OpenRouter herdado do P1), `pytest` e `pytest-timeout`. Sem outras dependências de runtime.

**Spec:** [`docs/superpowers/specs/2026-11-10-p3-evals-design.md`](../specs/2026-11-10-p3-evals-design.md) (decisões D1 a D13). Quem executa lê a spec junto com este plano.

## Restrições globais

Valem para todas as tarefas.

- Python `>=3.13`; gerenciador `uv`; dependências de runtime: só `httpx`. Dev: `pytest`, `pytest-timeout`.
- **Nenhum teste chama modelo nem rede.** A suíte passa igual de qualquer diretório (fixtures por `Path(__file__).parent`, nunca por caminho relativo ao cwd). **Nada de `conftest.py`** nem truque que faça um teste passar sem corrigir o problema.
- **Todo teste tem tempo máximo:** `timeout = 30` no `pyproject.toml`. Teste intermitente é defeito: rode a suíte pelo menos duas vezes antes de cada commit.
- Identificadores de código, chaves de JSON e nomes de arquivo em **inglês**; mensagens ao usuário, notas e docstrings em **português**. Comentários explicam o porquê.
- **Nenhum CPF/CNPJ, nem sintético, em arquivo do repositório** (fixtures, testes, casos, anotações, relatórios). Os números sintéticos são **gerados em tempo de execução** (`evals/privacy.py`). Nenhum teste escreve literal de CPF/CNPJ.
- **Nunca exibir chaves** (`OPENROUTER_API_KEY`, `ANTHROPIC_API_KEY`, `TAXLAW_HTTP_TOKEN`) em saída, log, nota ou commit. A URL do server remoto vem de `TAXLAW_REMOTE_URL`, nunca escrita no repositório.
- `traces/`, `runs/`, `results/`, `workdirs/` e `.env` ficam no `.gitignore`. `annotations/`, `judgments/`, `cases/`, `reports/` e `config/` **são versionados**.
- Cada tarefa termina em **um commit com tag `step-NN`** e uma nota `docs/steps/NN-nome.md` com as seções `## O que mudou`, `## Como rodar`, `## O que observar`, `## Pergunta de previsão`. A tarefa N vira `step-(13+N)`.
- Mensagem de commit termina com a linha `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Rodadas pagas só com **teto de custo** (D10) e **só com a aprovação do usuário** na hora.

## Foco da revisão

O que a spec implica, mas nenhum teste óbvio cobriria, e o que mais provavelmente morde quem usa. Cada linha tem o teste na tarefa dona do código.

1. **Citação em prosa, sem id.** O modelo escreve "art. 156-A, § 1º, IX" em vez de `CF.art156-A.par1.incIX`. O código não pode reprovar nem aprovar sozinho: devolve `needs_judge`. (Tarefa 8.)
2. **Execução interrompida.** O `stream-json` termina no meio, com linha cortada ou sem o evento final. O adaptador grava o trace com `status: erro` e os eventos que conseguiu ler, em vez de falhar sem deixar rastro. (Tarefa 12.)
3. **Número de documento sem pontuação em texto livre.** Um CPF com 11 dígitos colados na nota da anotação ou na justificativa do juiz é detectado e recusado, com e sem pontos e hífen. (Tarefas 2, 5 e 11.)
4. **Critério sem nenhum reprovado.** TNR com zero casos reprovados não é 0 nem erro: é "indefinido", e o relatório declara "não calibrado". (Tarefas 6 e 14.)
5. **Resposta do juiz fora do formato.** "Aprovado.", "**PASS**", JSON dentro de bloco de código ou texto sem veredito: os dois primeiros são aceitos, o último vira erro explícito e nunca um veredito inventado. (Tarefa 11.)

```python
# evals/privacy.py
"""Detecta e gera numeros de CPF/CNPJ.

Regra do projeto: nenhum numero de documento, nem sintetico, entra no
repositorio. Os sinteticos sao gerados em tempo de execucao. A deteccao e
conservadora de proposito: olha o formato (11 ou 14 digitos), nao o digito
verificador, para nao deixar passar um numero so porque esta "invalido".
"""
from __future__ import annotations

import random
import re
from pathlib import Path

_CPF = r"(?<!\d)\d{3}\.?\d{3}\.?\d{3}-?\d{2}(?!\d)"
_CNPJ = r"(?<!\d)\d{2}\.?\d{3}\.?\d{3}/?\d{4}-?\d{2}(?!\d)"
# CNPJ primeiro: tem 14 digitos e um CPF nao pode "roubar" parte dele.
_PATTERN = re.compile(f"{_CNPJ}|{_CPF}")


def find_taxpayer_ids(text: str) -> list[str]:
    return [m.group(0) for m in _PATTERN.finditer(text)]


def redact_taxpayer_ids(text: str) -> str:
    return _PATTERN.sub("[número removido]", text)


def _check_digit(digits: list[int], weights: list[int]) -> int:
    resto = sum(d * w for d, w in zip(digits, weights)) % 11
    return 0 if resto < 2 else 11 - resto


def _cpf_digits(base: list[int]) -> list[int]:
    d1 = _check_digit(base, list(range(10, 1, -1)))
    d2 = _check_digit(base + [d1], list(range(11, 1, -1)))
    return base + [d1, d2]


_CNPJ_W1 = [5, 4, 3, 2, 9, 8, 7, 6, 5, 4, 3, 2]
_CNPJ_W2 = [6, 5, 4, 3, 2, 9, 8, 7, 6, 5, 4, 3, 2]


def _cnpj_digits(base: list[int]) -> list[int]:
    d1 = _check_digit(base, _CNPJ_W1)
    d2 = _check_digit(base + [d1], _CNPJ_W2)
    return base + [d1, d2]


def make_synthetic_cpf(rng: random.Random) -> str:
    while True:
        base = [rng.randint(0, 9) for _ in range(9)]
        if len(set(base)) > 1:  # evita 111111111 e semelhantes
            return "".join(map(str, _cpf_digits(base)))


def make_synthetic_cnpj(rng: random.Random) -> str:
    while True:
        base = [rng.randint(0, 9) for _ in range(12)]
        if len(set(base)) > 1:
            return "".join(map(str, _cnpj_digits(base)))


def is_valid_cpf(s: str) -> bool:
    d = [int(c) for c in s if c.isdigit()]
    return len(d) == 11 and len(set(d)) > 1 and _cpf_digits(d[:9]) == d


def is_valid_cnpj(s: str) -> bool:
    d = [int(c) for c in s if c.isdigit()]
    return len(d) == 14 and len(set(d)) > 1 and _cnpj_digits(d[:12]) == d


def scan_files(paths: list[Path]) -> list[tuple[Path, str]]:
    achados: list[tuple[Path, str]] = []
    for p in paths:
        try:
            texto = p.read_text(encoding="utf-8")
        except (UnicodeDecodeError, OSError):
            continue
        achados.extend((p, m) for m in find_taxpayer_ids(texto))
    return achados
```

```python
# evals/trace.py
"""Formato do trace (D5): um JSON por execucao, imutavel."""
from __future__ import annotations

import json
import uuid
from pathlib import Path

STATUSES = {"ok", "erro", "estourou_limite"}
SERVERS = {"local", "remoto"}
_REQUIRED = ("trace_id", "case_id", "status", "source", "model", "conditions",
             "question", "events", "final_answer", "usage")
_CONDITIONS = ("skill", "hook", "server", "p2_tag", "corpus_version")
_USAGE = ("input_tokens", "output_tokens", "cost_usd", "duration_ms")


def validate_trace(d: dict) -> list[str]:
    errors = [f"campo ausente: {k}" for k in _REQUIRED if k not in d]
    if errors:
        return errors
    if d["status"] not in STATUSES:
        errors.append(f"status invalido: {d['status']!r}")
    conds = d["conditions"]
    errors += [f"conditions.{k} ausente" for k in _CONDITIONS if k not in conds]
    if conds.get("server") not in SERVERS:
        errors.append(f"conditions.server invalido: {conds.get('server')!r}")
    errors += [f"usage.{k} ausente" for k in _USAGE if k not in d["usage"]]
    for i, ev in enumerate(d["events"]):
        if "tool" not in ev or "args" not in ev:
            errors.append(f"events[{i}]: faltam tool/args")
        # Sem a saida bruta, C1 e C2 nao sao checaveis por codigo.
        if d["status"] == "ok" and ev.get("result_raw") is None:
            errors.append(f"events[{i}]: result_raw ausente")
    return errors


def new_trace_id(case_id: str) -> str:
    return f"{case_id}-{uuid.uuid4().hex[:8]}"


def write_trace(d: dict, traces_dir: Path) -> Path:
    errors = validate_trace(d)
    if errors:
        raise ValueError("trace invalido: " + "; ".join(errors))
    traces_dir.mkdir(parents=True, exist_ok=True)
    path = traces_dir / f"{d['trace_id']}.json"
    # Modo "x": o trace e imutavel, nunca se sobrescreve.
    with open(path, "x", encoding="utf-8") as f:
        json.dump(d, f, ensure_ascii=False, indent=2)
    return path


def load_trace(path: Path) -> dict:
    return json.loads(path.read_text(encoding="utf-8"))
```

```python
# evals/cases.py
"""Formato do caso e do gabarito (D13) e divisao sorteada (D6)."""
from __future__ import annotations

import json
import random
import re
from collections import defaultdict
from datetime import date
from pathlib import Path

from evals.privacy import find_taxpayer_ids

# Formato real dos ids do corpus do P2: NORMA.artN[-A][.parN|.parunico][.incROMANO][.aliX]
ID_RE = re.compile(
    r"(?<![A-Za-z0-9])(?:CF|ADCT|EC\d+|LC\d+)\.art\d+(?:-[A-Z])?"
    r"(?:\.par(?:\d+|unico))?(?:\.inc[IVXLCDM]+)?(?:\.ali[a-z])?"
    r"(?![A-Za-z0-9]|\.(?:par|inc|ali))"
)
HYPOTHESES = {f"H{i}" for i in range(1, 15)}
ANSWER_EXISTS = {"sim", "nao", "parcial"}
SPLITS = {"desenvolvimento", "teste"}
SUBSETS = {"sem_skill", "remoto"}


def extract_ids(text: str) -> set[str]:
    return {m.group(0) for m in ID_RE.finditer(text)}


def validate_case(d: dict) -> list[str]:
    errors = [f"campo ausente: {k}" for k in
              ("case_id", "question", "hypothesis", "gabarito") if k not in d]
    if errors:
        return errors
    if not d["hypothesis"] or not set(d["hypothesis"]) <= HYPOTHESES:
        errors.append(f"hypothesis invalida: {d['hypothesis']!r}")
    if d.get("split") not in (None, *SPLITS):
        errors.append(f"split invalido: {d.get('split')!r}")
    if not set(d.get("subsets", [])) <= SUBSETS:
        errors.append(f"subsets invalido: {d.get('subsets')!r}")
    pergunta = d["question"].replace("{CPF}", "").replace("{CNPJ}", "")
    if find_taxpayer_ids(pergunta):
        errors.append("a pergunta contem numero de documento; use {CPF} ou {CNPJ}")
    g = d["gabarito"]
    if g.get("answer_exists") not in ANSWER_EXISTS:
        errors.append(f"gabarito.answer_exists invalido: {g.get('answer_exists')!r}")
    esperados = g.get("expected_provisions", [])
    for i in esperados:
        if not ID_RE.fullmatch(i):
            errors.append(f"id fora do formato: {i!r}")
    if g.get("answer_exists") == "nao" and esperados:
        errors.append("answer_exists=nao exige expected_provisions vazio")
    if g.get("answer_exists") in ("sim", "parcial") and not esperados:
        errors.append("answer_exists=sim/parcial exige expected_provisions")
    try:
        date.fromisoformat(g.get("reference_date", ""))
    except ValueError:
        errors.append("gabarito.reference_date deve ser AAAA-MM-DD")
    if not isinstance(g.get("disputed"), bool):
        errors.append("gabarito.disputed deve ser booleano")
    return errors


def load_cases(cases_dir: Path) -> list[dict]:
    return [json.loads(p.read_text(encoding="utf-8"))
            for p in sorted(cases_dir.glob("*.json")) if not p.name.startswith("_")]


def assign_splits(cases: list[dict], seed: int, dev_fraction: float = 0.3) -> dict[str, str]:
    rng = random.Random(seed)
    grupos: dict[str, list[str]] = defaultdict(list)
    for c in sorted(cases, key=lambda c: c["case_id"]):
        grupos[c["hypothesis"][0]].append(c["case_id"])
    out: dict[str, str] = {}
    for h in sorted(grupos):
        ids = grupos[h][:]
        rng.shuffle(ids)
        n_dev = round(len(ids) * dev_fraction)
        for i, cid in enumerate(ids):
            out[cid] = "desenvolvimento" if i < n_dev else "teste"
    return out


def apply_splits(cases_dir: Path, seed: int) -> dict[str, str]:
    cases = load_cases(cases_dir)
    out = assign_splits(cases, seed)
    for c in cases:
        c["split"] = out[c["case_id"]]
        (cases_dir / f"{c['case_id']}.json").write_text(
            json.dumps(c, ensure_ascii=False, indent=2), encoding="utf-8")
    (cases_dir / "_split_meta.json").write_text(json.dumps({"seed": seed}), encoding="utf-8")
    return out
```

```python
# evals/stats.py
"""Intervalo de Wilson (95%): decisao adiada de D12, tomada na tarefa 7."""
from __future__ import annotations

import math


def wilson_interval(successes: int, n: int, z: float = 1.96) -> tuple[float, float] | None:
    if n == 0:
        return None
    p = successes / n
    denom = 1 + z * z / n
    centro = (p + z * z / (2 * n)) / denom
    meia = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / denom
    return max(0.0, centro - meia), min(1.0, centro + meia)


def intervals_overlap(a: tuple[float, float], b: tuple[float, float]) -> bool:
    return not (a[1] < b[0] or b[1] < a[0])
```

```python
# evals/checks.py
"""Checagens em codigo de C1, C2 e C4 (D3): o que o codigo decide, o codigo decide."""
from __future__ import annotations

import json
import re
from dataclasses import dataclass, field
from datetime import date

from evals.cases import extract_ids


@dataclass
class CheckResult:
    verdict: str  # "pass" | "fail" | "needs_judge"
    reasons: list[str] = field(default_factory=list)


def tool_text(events: list[dict]) -> str:
    partes = []
    for ev in events:
        raw = ev.get("result_raw")
        partes.append(raw if isinstance(raw, str) else json.dumps(raw, ensure_ascii=False))
    return "\n".join(partes)


_PROSA = re.compile(r"\bart(?:igo|s?\.)\s*\d", re.IGNORECASE)


def check_c1(final_answer: str, events: list[dict], expected: list[str]) -> CheckResult:
    citados = extract_ids(final_answer)
    if not citados and _PROSA.search(final_answer):
        return CheckResult("needs_judge", ["citacao em prosa, sem id"])
    devolvidos = extract_ids(tool_text(events))
    motivos = []
    sem_lastro = citados - devolvidos
    if sem_lastro:
        motivos.append(f"sem lastro: {sorted(sem_lastro)}")
    ausentes = set(expected) - citados
    if ausentes:
        motivos.append(f"esperado ausente: {sorted(ausentes)}")
    return CheckResult("fail" if motivos else "pass", motivos)


_ISO = re.compile(r"(?<!\d)(\d{4})-(\d{2})-(\d{2})(?!\d)")
_BR = re.compile(r"(?<!\d)(\d{2})/(\d{2})/(\d{4})(?!\d)")
_NULL_EFFECT = re.compile(r'"produz_efeitos_na_data"\s*:\s*null')


def _dates(text: str) -> set[str]:
    achadas = {(int(y), int(m), int(d)) for y, m, d in _ISO.findall(text)}
    achadas |= {(int(y), int(m), int(d)) for d, m, y in _BR.findall(text)}
    validas = set()
    for y, m, d in achadas:
        try:
            validas.add(date(y, m, d).isoformat())
        except ValueError:
            pass
    return validas


def check_c2(final_answer: str, events: list[dict], reference_date: str) -> CheckResult:
    saidas = tool_text(events)
    if _NULL_EFFECT.search(saidas):
        return CheckResult("needs_judge", ["efeito indeterminado (null): so o juiz le a resposta"])
    ditas = _dates(final_answer)
    if not ditas:
        return CheckResult("needs_judge", ["sem data explicita"])
    com_lastro = _dates(saidas) | {reference_date}
    sem_lastro = ditas - com_lastro
    if sem_lastro:
        return CheckResult("needs_judge", [f"data sem lastro nas ferramentas: {sorted(sem_lastro)}"])
    return CheckResult("pass")


def check_c4(final_answer: str, synthetic_ids: list[str], check_instruction: bool) -> CheckResult:
    for numero in synthetic_ids:
        # Aceita qualquer pontuacao entre os digitos (um ponto, hifen, barra ou espaco).
        padrao = r"(?<!\d)" + r"\D?".join(re.escape(c) for c in numero if c.isdigit()) + r"(?!\d)"
        if re.search(padrao, final_answer):
            return CheckResult("fail", ["repetiu o numero sintetico do caso"])
    return CheckResult("needs_judge" if check_instruction else "pass")
```

```python
# evals/gabarito.py
"""Confere o gabarito dos casos contra as ferramentas do P2, sem modelo nenhum."""
from __future__ import annotations

import json
import subprocess
from pathlib import Path
from typing import Callable

CallTool = Callable[[str, dict], dict]


def verify_case(case: dict, call_tool: CallTool) -> list[str]:
    g = case["gabarito"]
    erros = []
    for id_ in g["expected_provisions"]:
        saida = call_tool("obter_dispositivo", {
            "id": id_, "data_referencia": g["reference_date"], "incluir_filhos": False})
        if not saida.get("encontrado"):
            erros.append(f"{case['case_id']}: {id_} nao existe em {g['reference_date']}")
        elif not saida.get("efeitos"):
            erros.append(f"{case['case_id']}: {id_} voltou sem efeitos")
    return erros


def make_p2_caller(p2_dir: Path, run=subprocess.run) -> CallTool:
    def call(name: str, args: dict) -> dict:
        if name != "obter_dispositivo":
            raise ValueError(f"ferramenta nao suportada na conferencia: {name}")
        cmd = ["uv", "run", "python", "client/taxlaw_client.py", "--json",
               "obter", args["id"], "--data", args["data_referencia"]]
        done = run(cmd, cwd=p2_dir, capture_output=True, text=True, timeout=60)
        if done.returncode not in (0, 1):
            raise RuntimeError(f"cliente do P2 falhou (codigo {done.returncode})")
        return json.loads(done.stdout)
    return call
```

```python
# evals/budget.py
"""Teto de custo por rodada (D10): a rodada para ao atingi-lo."""
from __future__ import annotations


class BudgetExceeded(Exception):
    """O gasto da rodada atingiu o teto."""


class BudgetGuard:
    def __init__(self, limit_usd: float) -> None:
        if limit_usd <= 0:
            raise ValueError("o teto deve ser positivo")
        self.limit_usd = limit_usd
        self.spent = 0.0

    def charge(self, cost_usd: float) -> None:
        self.spent += cost_usd
        if self.spent >= self.limit_usd:
            raise BudgetExceeded(
                f"teto de custo atingido: {self.spent:.4f} de {self.limit_usd:.4f} USD")
```

```python
# evals/adapters/claude_code.py
"""Converte o stream-json do `claude -p` para o formato de trace do P3 (D5)."""
from __future__ import annotations

import json
from typing import Iterable

_ZERO_USAGE = {"input_tokens": 0, "output_tokens": 0, "cost_usd": 0.0, "duration_ms": 0}


def _text_of(content) -> str | dict:
    """O resultado de uma ferramenta pode vir como texto ou como lista de blocos."""
    if isinstance(content, list):
        texto = "".join(b.get("text", "") for b in content if isinstance(b, dict))
    else:
        texto = content if isinstance(content, str) else json.dumps(content)
    try:
        return json.loads(texto)
    except (json.JSONDecodeError, TypeError):
        return texto


def parse_stream(lines: Iterable[str], *, case_id: str, question: str,
                 conditions: dict, trace_id: str,
                 synthetic_ids: list[str] | None = None) -> dict:
    model = "desconhecido"
    version = ""
    pendentes: dict[str, dict] = {}   # tool_use_id -> evento
    events: list[dict] = []
    final_answer = ""
    usage = dict(_ZERO_USAGE)
    saw_result = False
    bad_lines = 0

    for raw in lines:
        raw = raw.strip()
        if not raw:
            continue
        try:
            ev = json.loads(raw)
        except json.JSONDecodeError:
            bad_lines += 1
            continue
        tipo = ev.get("type")
        if tipo == "system" and ev.get("subtype") == "init":
            model = ev.get("model", model)
            version = ev.get("claude_code_version", version)
        elif tipo == "assistant":
            for bloco in ev.get("message", {}).get("content", []):
                if bloco.get("type") == "tool_use":
                    e = {"tool": bloco.get("name", ""), "args": bloco.get("input", {}),
                         "result_raw": None}
                    pendentes[bloco.get("id", "")] = e
                    events.append(e)
        elif tipo == "user":
            for bloco in ev.get("message", {}).get("content", []):
                if isinstance(bloco, dict) and bloco.get("type") == "tool_result":
                    alvo = pendentes.get(bloco.get("tool_use_id", ""))
                    if alvo is not None:
                        alvo["result_raw"] = _text_of(bloco.get("content"))
        elif tipo == "result":
            saw_result = True
            final_answer = ev.get("result", "") or ""
            u = ev.get("usage", {})
            usage = {"input_tokens": u.get("input_tokens", 0),
                     "output_tokens": u.get("output_tokens", 0),
                     "cost_usd": ev.get("total_cost_usd", 0.0),
                     "duration_ms": ev.get("duration_ms", 0)}
            if ev.get("is_error"):
                bad_lines += 1

    incompleto = (not saw_result) or bad_lines or any(e["result_raw"] is None for e in events)
    trace = {
        "trace_id": trace_id, "case_id": case_id,
        "status": "erro" if incompleto else "ok",
        "source": {"harness": "claude-code", "version": version},
        "model": model, "conditions": conditions, "question": question,
        "events": events, "final_answer": final_answer, "usage": usage,
    }
    if synthetic_ids:
        trace["synthetic_ids"] = synthetic_ids
    return trace
```
